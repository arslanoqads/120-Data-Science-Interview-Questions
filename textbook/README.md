# AI Engineer / FDE Curriculum — Textbook

Compiled course chapters synthesized from `research/` notes. **Research is the only source of truth**; chapters do not invent capabilities beyond those notes.

## Compilation rule

Compile **one week at a time**. A week’s **Compile** column is `COMPLETE` when its chapter covers every syllabus concept with the full concept structure.

## Editorial rule

Edit **one week at a time** for pedagogical continuity. A week’s **Edit** column is `COMPLETE` only when:

1. Continuity with the previous chapter is reviewed  
2. A brief **Prerequisites Recap** opens the chapter (Week 1: course entry assumptions)  
3. Formatting is standardized and transitions are smooth  
4. Language is coherent and simple without inventing new technical claims  

Do not start editing week *N+1* until week *N* Edit is COMPLETE.

## Standard chapter front matter

1. Title + metadata block (`Phase`, `Editorial status`, `Source of truth`, `Syllabus Build`)  
2. **Prerequisites Recap**  
3. **What this week builds** (short framing)  
4. Concept sections (structure below)  
5. **Week N build checklist**  
6. **Looking ahead** (bridge to next week; omit on Week 29)

## Chapter concept structure

Each concept uses:

1. **Fundamentals**
2. **The Alternatives**
3. **Failure Modes**
4. **Average vs. Strong Engineer**
5. **Worked Example** (tied to the week’s Build)
6. **Apply It**

If research lacks grounding for a section: `[NEEDS MORE RESEARCH]`.
