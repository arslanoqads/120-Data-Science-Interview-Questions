## Syllabus build task (Week 14)

Ship a **second, smaller agentic system** whose job is to **change the world** — not to answer a question. Week 11–13 already have a loop, MCP, and a graph with HITL. This week adds **real writes** plus the four controls that keep writes from exploding.

1. Pick **one** domain write (recommended: **issue a refund** against a fake payments table **or** create a calendar event **or** file a ticket in a real/staging tracker). Reads-only does not count.  
2. Split tools: `lookup_*` (read) vs `preview_*` / `propose_*` vs `commit_*`. The model **cannot** reach the write path without going through preview **or** a confirmation token.  
3. Every write tool requires an **idempotency key** generated by the **wrapper** (user id + object id + intent + A2A `taskId` / graph `thread_id`) — **never** by the LLM. Prove timeout + retry does **not** double-apply (Stripe pattern).  
4. Gate irreversible / high-value commits with Week 13 **`interrupt()`** **or** a tokenized propose/commit pair. Payload must show blast radius (amount, recipient, row ids).  
5. After commit, **read back** the environment (SQL row, Stripe object, ticket id). Treat that as truth. The assistant saying “done” is not success.  
6. Emit an **append-only audit record** *before* the write (intent) and *after* (result): actor, tool, redacted args, idempotency key, approval id, downstream id.  
7. **Optional A2A slice:** wrap the specialist (refund / scheduler) as an A2A **server** with an Agent Card; the client orchestrator delegates a **Task** instead of in-process tool call. Propagate `taskId` into the idempotency key and audit log. Skip A2A only if both agents are the same process — then document why.

Do **not** skip this week for “the model promised it would be careful.” You cannot debug Week 15 trajectories if writes are implicit, duplicated, or unaudited.

## Default path (synthesis)

1. **MCP inside** an agent (tools/data); **A2A between** opaque agents. Do not replace one with the other ([A2A ❤️ MCP](https://a2a-protocol.org/latest/topics/a2a-and-mcp/)).  
2. Prefer a **workflow** for the write SOP (verify identity → preview → gate → commit → read-back) and an **agent** only for the conversational / lookup part ([Building effective agents](https://www.anthropic.com/engineering/building-effective-agents)).  
3. Idempotency lives in the **tool wrapper / API**, not in the prompt. Keys from stable business identity ([Stripe idempotent requests](https://docs.stripe.com/api/idempotent_requests)).  
4. Confirmation is **structural** (token consume or graph interrupt). Prompt-only “please confirm” is not a control.  
5. Grade **environment outcome** in tests even this week (row exists, amount matches). Full trajectory eval is Week 15 ([Demystifying evals](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents)).  
6. Interview artifact = **one successful write + one retry that did not duplicate + one rejected gate + an audit line** — optionally plus an Agent Card URL.
